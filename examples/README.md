# Examples

- `glasshome-config.demo.yaml`: demo mode, a fictional home, for trying Glass Home before setting it up.
- `glasshome-config.minimal.yaml`: the smallest useful settings (weather, lights, one room, thermostat).
- `../config/glasshome-config.example.yaml`: every option, with fictional values.

Each one goes in `/config/glasshome/config.yaml`, next to the dashboard file. Never in `/config/www`.
